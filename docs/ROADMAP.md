# Roadmap

## Phase 1: Foundation

- Android foreground service
- Embedded HTTP server
- SQLite migrations
- Health endpoint
- User PIN login
- Device identity

## Phase 2: Core ordering

- Table grid
- Table sessions
- Product catalog
- Order and line management
- Modifier validation
- Server-side totals

## Phase 3: Kitchen workflow

- Kitchen submissions
- Persistent print queue
- Simulated printer
- ESC/POS network printing
- Retry and reprint

## Phase 4: Cashier settlement

- Open orders
- Cash payment
- Atomic checkout
- Receipt printing
- Table release

## Phase 5: Back office

- Products
- Categories
- Modifier groups
- Tables
- Users
- Payment methods
- Printers

## Phase 6: Reliability

- Idempotent commands
- Optimistic concurrency
- Restart recovery
- Printer diagnostics
- Audit history

## Phase 7: Synchronization

- Local outbox
- Cloud acknowledgements
- Configuration download
- Conflict policy
- Sync status UI

## Phase 8: Reports

- Daily sales
- Payment method summary
- Product sales
- Open orders
- Cancelled and voided orders
